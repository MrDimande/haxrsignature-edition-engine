# Nian image assets

## Layout

- `originals/` — masters intactos (nunca sobrescrever)
- `social/` — poster + Open Graph (tipografia baked-in OK)
- `cinematic/` — WebP optimizados para a experiência
- `hero/` — `nian-hero-clean.webp` (pending)

## Regras

- O **poster** (`social/nian-poster.png`) não é background do Hero.
- Hero usa tipografia HTML até existir `hero/nian-hero-clean.webp`.
- Cinematic plates com brilho no canto: usar `NianImageArtifactMask`.
